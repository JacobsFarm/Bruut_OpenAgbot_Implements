# Lime spreader

**Status: idea, not worked out yet.** Category: Spraying, Fertilizing & Irrigation.

## What it does

Spreading lime to improve soil pH levels and structure.

## Concept (first thoughts)

Like the fertilizer spreader, but with a coarser metering roller or belt for powdery or granular lime and a covered outlet against dust. Large dose per hectare means large hopper volume, so reloading logistics matter.

## Reuse from existing implements

Fertilizer spreader hopper and metering; mobile refiller for reloading.

## Open questions

- Dose per hectare and hopper volume
- Dust control and flow behaviour of damp lime
- Reloading: how often per hectare?
