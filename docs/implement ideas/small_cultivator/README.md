# Small cultivator

**Status: idea, not worked out yet.** Category: Soil Cultivation & Weed Control.

## What it does

Compact cultivator for soil cultivation in vegetable gardens and light plots.

## Concept (first thoughts)

A toolbar with 3 to 5 spring or rigid tines on a parallel linkage, depth set by gauge wheels. Light soil only, so draft force stays within what the robot can pull. Optionally a rolling basket behind the tines.

## Reuse from existing implements

Toolbar, parallelogram and gauge wheels of the in-row weeder and the liquid fertilizer applicator.

## Open questions

- Draft force per tine in light soil (measure)
- Tine spacing versus working width
- Ballast needed to keep the tines in the ground
