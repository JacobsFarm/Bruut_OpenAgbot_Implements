# Straw spreader

**Status: idea, not worked out yet.** Category: Spreading & Bedding.

## What it does

Evenly spreading straw, specially designed for use between vegetable rows.

## Concept (first thoughts)

A bale rack or bin with a shredding and metering unit that drops straw as a narrow strip between rows, for weed suppression and moisture. Width limited to the inter-row space of 375 mm rows (the wheels run in the inter-rows).

## Reuse from existing implements

Row geometry of the in-row weeder; metering from the sawdust spreader.

## Open questions

- Bale handling or loose straw bin
- Strip width and thickness between rows
- Blocking of the metering unit by long straw
