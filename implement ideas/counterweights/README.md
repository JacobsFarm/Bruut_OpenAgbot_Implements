# Counterweights

**Status: idea, not worked out yet.** Category: Transport & General.

## What it does

Ballast weights to improve traction and vehicle balance for heavy tasks.

## Concept (first thoughts)

Plates or blocks that clip onto the beams on the 50 mm grid, front and rear, so the centre of gravity can be tuned. Several implements already call for ballast (weed picker, overseeder, liquid applicator v2).

## Reuse from existing implements

Ballast notes in the RATIONALE.md of the weed picker, overseeder and applicator.

## Open questions

- Block mass and handling by one person
- Position range front/rear
- Quick-release mounting
